# 本地需求引导实现与离线验收

日期：2026-10-01。主责：服务器 Agent。基线 main：`4a76edaa3ec333bb4e709673c9478cd8c764f333`；工作分支：`codex/local-needs-guidance`。用户在方案后授权“执行”，本轮完成代码与离线验证，未提交、推送或合并。

## 已交付

- `core/schemas.py`：八维度状态合同，区分 missing、known、unknown、refused、explicit_none、conflict；保留候选值、证据、问题、回答原文、轮次与停止原因。时间预算支持 0–168 小时的小数。
- `core/intake.py`：原八维度键名不变，学历别名统一；明确回答替换旧值，未知/拒答/明确无不再混同。空回答保留尝试记录；时间范围、负数和非法值不猜测成单个小时数。
- `core/guidance.py`：材料先行，校验本地模型返回的字段与证据原文，优先澄清矛盾，再针对缺失或模糊目标单题询问。已问问题去重；未知、拒答、明确无不因空值重问；用户确认后解决冲突，旧材料不再次推翻已确认回答。
- `core/local_guidance.py`：已有 Qwen3-4B 文本模型适配器，惰性加载、仅本地文件、显式 CUDA 设备、禁止 CPU 回退与远程代码；限定输入 8192 tokens、输出 1024 tokens、严格 JSON 校验，不做自动重试。
- `orchestrator.py` / `assistant_cli.py`：准备结果复用于普通/流式规划，感知仅一次；恢复完整历史画像；答案进入知识检索和实际规划提示词。跳过、轮次上限、用户停止和模型错误保留原因。模型错误后只有用户明确输入“继续”才进入规划。
- 既有 SQLite 与 JSONL 保存脱敏后的回答及证据链，不改变表结构。普通 CLI 展示隐藏引导内部记录，`--debug-trace` 可查看，存储中仍保留完整脱敏记录。

`--answers-json` 接受八维度字符串答案，部分答案不再跳过全部追问。`--no-follow-up` 不调用引导模型，但仍执行原有感知与最终规划，不能当作离线运行开关。直接调用编排器 `run` / `run_stream` 而不传准备结果时保持非交互兼容，记录 not_requested，不声称运行了模型引导。

## 配置与剩余验收

`GUIDANCE_MODEL_PATH` 需指向服务器已有 Qwen3-4B-Instruct-2507 目录；默认留空以要求明确配置。本轮没有修改私有 `.env`。`GUIDANCE_MAX_ROUNDS` 默认 4，可配置 0–16；这是本轮实施参数，不来自成员 C 的历史 8 轮规则。成员 C 回执已读，未导入其规则、资料或岗位排序。
