# 项目决定

## 当前有效决定：2026-09-29

1. 唯一依据是原版获批申报书；第二版比较研究和独立论文不属于本项目。
2. 只接收本机b96d14d基线及服务器7995c62快照。其他未合并分支不采用，不删除远端分支。
3. 用户批准按清单删除无用内容，不要求另建归档；不删除原始运行数据、权重或未知个人文件。
4. 唯一交付入口为Ubuntu服务器CLI，网页/API/Docker不作为产品组成。
5. 最终推理智能体用DeepSeek API；其他模型型智能体使用服务器本地GPU。禁止CPU模型加载与回退；纯逻辑测试不受此限制。
6. 本机完成清理、基线同步、计划和交接后退出日常执行。提交推送仍等待最终差异与测试审阅。
7. 需要真实完成需求引导、反馈后输出修改；不得用固定八题、反馈落盘冒充完整智能体。
