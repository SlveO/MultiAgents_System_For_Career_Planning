## 同步要求

发布前查看git diff、测试结果及未跟踪文件清单，只显式暂存本任务文件，不包含log.txt、output/、data/或模型。
共享分支由负责人确认，不自动修改GitHub默认分支。服务器可用新worktree接收，保留原开发目录未提交状态。
两端分别提供git rev-parse HEAD及git status；一致指版本管理的源码与文档，不指虚拟环境或绝对路径。
