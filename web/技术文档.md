## 1. 项目概述

本项目是一套集**对话助手、职业规划工具、待办事项管理、番茄钟专注工具、翻页时钟**五大核心功能于一体的前端单页应用（SPA）。采用 **React 18 + Vite 5 + TypeScript 5** 现代化技术栈开发，仅依赖 lucide-react 图标库，无其他第三方 UI 框架。

核心面向**大学生职业规划咨询**与**个人时间管理**两大场景。

### 1.1 对话助手与职业规划功能的区分

在应用架构中，"对话助手"和"职业规划"是两个互补但不同的功能层级：

| 维度 | 对话助手（主功能） | 职业规划工具（子功能） |
|------|-------------------|----------------------|
| **定位** | 自由对话式 AI 聊天，用户可提问任何职业相关问题 | 结构化信息收集，通过预设模板快速生成专业提问 |
| **入口** | 导航栏"对话助手" tab | 对话助手页面右侧"职业规划提问"面板 |
| **交互方式** | 底部输入框自由输入 → AI 流式回复 | 点击 5 个快捷按钮 → 3 个需填写模态窗（专业/绩点等）→ 自动拼接 prompt 发送 |
| **数据流** | `sendMessage(userText)` | `handleSendMessage(builtPrompt)` |
| **适用场景** | 开放式职业咨询、追问、讨论 | 新生入学测评、考研决策、专业方向选择 |

**两者共享同一个聊天引擎**（SSE 流式调用 `/v1/multimodal/chat/stream`），区别仅在于前端如何组装发送给 AI 的消息文本。

## 3. 核心架构详解

### 3.1 状态管理架构

采用 **React Context + Hooks** 模式，4 个独立 Context Provider 嵌套：

```
<AuthProvider>
  <ChatProvider>
    <TodoProvider>
      <PomodoroProvider>
        <App />
      </PomodoroProvider>
    </TodoProvider>
  </ChatProvider>
</AuthProvider>
```

| Context | 持久化 | 核心状态 |
|---------|--------|----------|
| AuthContext | localStorage (`auth_user`, `access_token`) | user, isLoading, error |
| ChatContext | 服务端（通过 API） | sessions[], currentSession, isStreaming, historyVisible |
| TodoContext | localStorage (`todos`) | todos[], add/toggle/delete/reorder |
| PomodoroContext | localStorage (`pomodoro_settings`) | isRunning, currentPhase, timeLeft, settings |

### 3.2 API 层设计

**`client.ts` — 请求基础设施**：
- 所有请求自动注入 `Authorization: Bearer <token>`
- 15 秒超时（`AbortController`），防止连接挂起
- 401 响应自动清除 token 并触发登出
- `readSSEStream()` 使用 `fetch` + `ReadableStream` 读取 POST 端点的 SSE 事件流

**SSE 流式消息流程**：
```
用户输入 → ChatContext.sendMessage()
  → api/chat.ts: sendChatMessage()    [AsyncGenerator<string>]
    → POST /v1/multimodal/chat/stream  [SSE: event: token / data: {...}]
      → 逐 token 更新 AI 消息内容
        → 最后一个 token 到达 → isStreaming = false
```

### 3.3 组件层级与交互

```
<App>
  ├── [未登录] <AuthPage>
  │     ├── <LoginForm />     → api/auth.ts:login() → 存 JWT
  │     └── <RegisterForm />  → api/auth.ts:registerAndLogin()
  │
  └── [已登录]
        ├── <Header />        ← 应用标题 "大学生职业规划助手" + 登出按钮
        ├── <Navbar />        ← 对话助手 | 今日待办 (两个 tab)
        │
        ├── [tab='career'] 对话助手页
        │     ├── <HistorySidebar />  ← 始终渲染（可折叠，折叠时显示展开按钮）
        │     ├── <ChatContainer />
        │     │     ├── <MessageBubble />×N  用户蓝色/右对齐, AI白色/左对齐
        │     │     └── <TypingIndicator />   流式接收中显示
        │     ├── <ChatInput />
```

## 4. API 对接说明

### 4.1 已对接的后端接口

| 方法 | 路径 | 用途 | 认证 |
|------|------|------|------|
| POST | `/auth/register` | 用户注册 | 否 |
| POST | `/auth/login` | 用户登录，获取 JWT | 否 |
| POST | `/v1/multimodal/chat/stream` | SSE 流式聊天 | 可选 |
| GET | `/v1/multimodal/chat/session/{id}` | 获取会话历史 | 可选 |
| DELETE | `/v1/multimodal/chat/session/{id}` | 删除会话 | 可选 |
| POST | `/v1/upload` | 文件上传 (multipart) | 可选 |

### 4.2 Vite 代理配置

开发时 Vite 自动将 `/auth` 和 `/v1` 请求代理到 `http://localhost:8000`（FastAPI 后端）。无需手动配置 CORS。

### 4.3 后端自动启动

`vite.config.ts` 内置 `spawnBackend` 插件，`npm run dev` 时自动通过 `conda run -n agents python -m project.api.run_api` 启动后端。Vite 关闭时自动 kill 后端进程。

## 5. 应用使用方法

### 5.1 运行环境要求

- **Node.js** 18+
- **conda** 环境 `agents`（已安装后端依赖）
- Chrome 80+ / Firefox 75+ / Edge 80+

### 5.2 开发运行

```bash
cd web
npm install        # 首次：安装依赖
npm run dev        # 启动开发服务器 → http://localhost:5173
                   # 后端自动通过 conda run 启动
```

### 5.3 生产构建

```bash
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

### 5.4 核心功能使用

| 功能 | 操作 |
|------|------|
| 对话助手 | 点击"对话助手"tab → 输入问题 → 发送 → AI 流式回复 |
| 职业规划提问 | 右侧面板点击预设问题 → 填写信息模态窗 → 自动发送 |
| 历史对话 | 左侧侧边栏切换/新建/删除会话；点击 ↦ 按钮折叠/展开 |
| 今日待办 | 点击"今日待办"tab → 添加标题/描述 → 拖拽排序 → 点击查看详情 |
| 番茄钟 | 待办详情 → 点击"番茄钟" → 开始专注 → 自动阶段切换 + 通知 |
| 翻页时钟 | 待办详情 → 点击"翻页时钟" → 全屏 3D 翻转时钟 |

## 6. 常见问题与解决方案

| 问题现象 | 根因 | 解决方案 |
|----------|------|----------|
| 注册/登录失败（ECONNREFUSED） | 后端未启动 | 确认 conda 环境 `agents` 已配置；`npm run dev` 自动启动后端 |
| 聊天一直显示"思考中" | 后端连接超时 | 现已加入 15s 超时 + 明确错误提示；检查 `localhost:8000` 是否可达 |
| 收起侧边栏后无法恢复 | HistorySidebar 条件渲染导致按钮消失 | **已修复**：组件始终渲染，折叠状态仍显示展开按钮 |
| 翻页时钟无动画 | 浏览器不支持 CSS 3D transform | 使用最新版 Chrome/Edge/Firefox |
| 刷新后待办数据丢失 | 旧版数据仅存内存 | **已修复**：TodoContext 使用 localStorage 持久化 |
| 刷新后需重新登录 | JWT 过期 | AuthContext 将 token 存于 localStorage，过期后 401 自动登出 |

## 7. 维护与扩展规范

### 7.1 代码命名规范

- **React 组件**：PascalCase，文件名与组件名一致（`ChatInput.tsx` → `<ChatInput />`）
- **Hooks**：`use` 前缀（`useChat`, `useFlipClock`）
- **Context**：`XxxProvider` + `useXxx` hook 模式
- **TypeScript**：接口定义在 `src/types/index.ts`，使用 `type` / `interface` 区分
- **CSS**：全局动画/特效样式放在 `index.css`，组件样式优先使用 Tailwind 原子类

### 7.2 功能扩展规范

- 新增页面在 `src/components/` 下建独立目录
- 跨组件共享状态使用 Context（不引入 Redux）
- API 调用统一放在 `src/api/` 层
- 新增依赖需评估包体积影响（保持 gzip 总大小 < 100KB）
- 修改 vite.config.ts 后需重新 `npm run dev`
